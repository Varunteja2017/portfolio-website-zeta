## Software Development Projects

### Supply Planning System

A full-stack web application developed for Tech Mahindra to manage vehicle supply planning between Business Associates (BA), MLL Operations, and Admin.

Key Features:
- Role-based authentication (Admin, MLL Operations, BA)
- Vehicle registration and availability tracking
- Rate submission and approval workflow
- Real-time supply-demand planning dashboard
- Dark mode UI with responsive design

Tech Stack:
- Flask
- MySQL / SQLite
- HTML, CSS, JavaScript
- Tailwind CSS
